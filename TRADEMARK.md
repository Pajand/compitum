# Trademark Policy

This document exists because the project's name, **COMPITUM**, is an asset that has to be
defensible. It is also short, and it is worth being clear about when you may and may not
use it, so that nobody is confused and no goodwill is diluted.

## The mark

**COMPITUM** is used as the name of this open-source compatibility layer.

The name comes from Latin *compitum* — a crossroads, the point at which roads meet and a
direction must be chosen. That is precisely what this software does: it inspects an ARM64
binary and decides, with evidence, which execution path is correct.

## What you may do without asking

You do not need permission for any of the following:

- **Use the software.** The licence (Apache-2.0 OR MIT) already grants this.
- **Say that your product uses COMPITUM**, provided that is true. For example:
  *"Acme Runner uses the COMPITUM classifier."*
- **Write about it**, in articles, talks, tutorials, papers, or course material.
- **Fork it**, under the terms of the licence, including for commercial purposes.
- **Redistribute it**, unmodified or modified, provided you comply with the licence.
- **Sell services around it** — consulting, integration, support, hosting.

## What requires care

### Do

- Refer to it as *"the COMPITUM classifier"*, *"COMPITUM's Oracle"* — use the name as a
  proper adjective for the software.
- Make it obvious that your fork or product is **not** the official project when it
  differs from it. A sentence is enough: *"This is an unofficial fork; the original is
  at github.com/compitum-dev/compitum."*
- Keep the name spelled in capitals: **COMPITUM**.

### Do not

- Do not name your own project, company, or product *COMPITUM*, or a name confusingly
  close to it, in a way that suggests you are the official project.
- Do not use the name in a modified form — no *CompitumAI*, *CompitumXT*, *COMPITUM
  Cloud* — for your own product.
- Do not use the name to imply endorsement, sponsorship, or affiliation that does not
  exist.
- Do not register the name, or a confusingly similar variation of it, as a **trademark**,
  **domain name**, or **social media handle** in a way that competes with the project.
  This is the one that actually causes harm, because it can make the project itself
  unable to use its own name.
- Do not present a forked version as the official release.

## Domain and package namespaces

The project claims and defends the following. If you hold one of these and are not the
project, please get in touch rather than redirecting it somewhere that could confuse
users:

| Namespace | Where |
|---|---|
| Package | `compitum` on crates.io |
| Package | `compitum` on npm |
| Package | `compitum` on PyPI |
| Repository | `github.com/compitum-dev/compitum` |
| Domain | `compitum.dev` (primary) |

The project does **not** claim every use of the word. A restaurant, a bridge-management
system, or an unrelated software library named *Compitum* in a different field is not a
concern, and this policy makes no claim over such uses.

## Why this is written down

Because namespace claims made quietly are worthless. If the name is taken and the policy
is unwritten, the project has no recorded position to assert. This file is that record,
dated and versioned in the repository history.
